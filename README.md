## ✨ Features of the Landing Page

- **🖤 Ultra-Minimalist Zero-Gradient Design**: Pure Stark Black (`#000000`), solid white typography, neutral zinc borders, and high-contrast surfaces with zero CSS gradients.
- **📱 Real Video Phone Simulator**:
  - Live looping HTML5 vertical video stream with multi-clip Reddit playlist (`r/skateboarding`, `r/funnyvideos`, `r/Unexpected`).
  - Working **Hold-for-2X Speed** gesture: Click and hold on the right side of the screen to accelerate playback to 2.0X with HUD pill feedback.
  - Working **Sound Toggle**: In-place unmuting feedback.
  - Working **Double-Tap Upvote**: Heart animation with counter increment.
  - Background keyboard shortcuts (`Space` to play/pause, `J` for next clip, `K` for previous, `M` for mute).
- **🌊 Infinite Community Marquee**: Smooth-scrolling ribbon featuring top Reddit video communities (`r/Unexpected`, `r/funnyvideos`, `r/nextfuckinglevel`, `r/skateboarding`).
- **⚡ 4-Pillar Swiss Architecture Grid**:
  - **Hold for 2X Speed**: Interactive test button accelerating the HUD readout to 2.0X.
  - **Synchronized Audio**: Live audio visualizer equalizer demonstrating DASH and RedGIFs sound sync.
  - **60 FPS Virtual Feed**: High-performance virtualization with zero memory leaks.
  - **Guest Authentication**: Reddit Installed Client OAuth protocol details.
- **📲 Universal PWA Hub**:
  - Instant Web App launch on `snooflick.com`.
  - Step-by-step "Add to Home Screen" instructions for iOS Safari and Android Chrome standalone app installation.
- **🔒 Dedicated Privacy Policy Page**: Accessible directly at `https://snooflick.com/privacy` with SPA history routing.

## 🛠️ Tech Stack

- **Framework**: React 18, TypeScript
- **Bundler**: Vite 5
- **Styling**: Tailwind CSS v3, Custom Swiss Minimalist Tokens
- **Icons**: Lucide React
- **Deployment**: Vercel (`vercel.json`) on custom domain **`snooflick.com`**

## 🚀 Quick Start (Local Development)

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
